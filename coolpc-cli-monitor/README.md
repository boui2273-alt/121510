# CoolPC CLI Monitor

原價屋線上估價系統的最簡 CLI 監控工具：終端機常駐執行、定時自動抓取，
監控**開放式水冷 (n11)**、**機殼(+電源供應器) (n14)**、**電源供應器 (n15)**
三個分類的新增品項、價格異動與目前促銷總覽。

與 [`coolpc-monitor`](../coolpc-monitor)（Express + 瀏覽器儀表板）是同一目標的不同實作方式：
這裡改用 cheerio 解析、單一 JSON 檔 (`coolpc_db.json`) 當資料庫、純終端機輸出，
沒有網頁介面。

## 安裝與執行

```bash
cd coolpc-cli-monitor
npm install
npm start
```

啟動後會立即抓取一次，之後每 5 分鐘自動重新抓取並與上一輪比對
（可用環境變數調整：`POLL_INTERVAL_MS=60000 npm start` 改成每分鐘一次）。
按 `Ctrl+C` 結束。

## 已修正的問題

原始版本有三個會影響資料正確性的問題，目前的 `index.js` 已修正：

1. **跨分類 ID 互相覆蓋**：原本用原價屋的 `<option value>` 數字當唯一 key，
   但這個編號在每個 `<select>` 內各自從頭編號，n11/n14/n15 之間有大量重複
   （實測 n14 與 n15 就有 338 個重複編號）。同一數字在不同分類會覆蓋彼此，
   導致大部分商品「消失」。現在 key 改為 `${selectName}_${id}`，依分類做命名空間隔開。
2. **促銷商品抓到「原價」而非「現價」**：`原價$X ↘ $Y` 這種標記，原本的
   `text.match(/\$(\d+)/)` 只抓第一個金額 (X，折扣前原價)，現在改抓文字中
   **最後一個** `$` 金額 (Y，實際售價)。
3. **商品名稱混入倒數促銷文字**：品名切割前先去除 `▼下殺到 .../` 這類倒數標語，
   避免名稱尾端殘留促銷文案。

另外，把單次執行改成常駐迴圈時，原本抓取失敗會 `process.exit(1)` 直接關閉整個程式——
單一分類一次網路失敗就會讓自動更新永久停止。現在改成記錄錯誤、等待下一輪重試，
並加了重疊執行防呆（上一輪還沒跑完就不會啟動下一輪）。

## 資料檔

`coolpc_db.json`：完整商品快照，作為下一輪比對的基準。刪除這個檔案即可重置歷史紀錄
（下一次執行會視為初始建檔，不產生異動報告）。
